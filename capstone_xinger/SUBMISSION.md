## 三、运行说明（供评审复现）

```bash
# 环境要求
# Python 3.11（venv 内；requirements.txt 含 faiss-cpu/openai/requests/pdfplumber/streamlit 等）
pip install -r requirements.txt

# 配置密钥（.env.template 已给模板，.env 不入库）
#   MODELSCOPE_BASE_URL / MODELSCOPE_API_KEY   —— 必需（embed + 生成）
#   JINA_API_KEY                                —— 可选（rerank；不配或政企环境建议直接禁用）

# 建议政企/无外网环境用降级模式（一条环境变量，零代码改动）：
set RERANK_PROVIDER=none     # Windows；Linux/Mac: export RERANK_PROVIDER=none

# 方式 A：CLI 问答（推荐评审用，复现最快）
python ask.py "ZB2026-001 这个项目的预算金额是多少？"
python ask.py "数据中心运维服务的服务期是多久？" --role staff

# 方式 B：Streamlit 界面
streamlit run app.py          # 访问 http://localhost:8501

# 方式 C：重跑 13 题评测（产物 eval_result.json）
python eval_demo.py

# 方式 D：索引重建（data/ 换标书后）
python build_index.py
```

- **模型**：Embedding 用 Qwen3-Embedding-0.6B、生成用 Qwen3-8B（魔搭 ModelScope API-Inference，OpenAI 兼容协议，`enable_thinking=False` + 强制 JSON）；
- **检索**：本地 FAISS IndexFlatIP，向量粗筛 COARSE_K=20 → 相似度阈值 0.4 + 角色权限双过滤 → Jina rerank 精排 Top-5（rerank 不可用时自动回退向量粗排）；
- **实测**：13 题准确率 100%，事实题检索命中率 100%，P50 总耗时 ≈2.6s，3 个异常 case（未提及/模糊/乱码）全部得体拒答不编造。

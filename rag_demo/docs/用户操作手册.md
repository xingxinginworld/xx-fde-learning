# 招标文件问答助手 · 用户操作手册

> 适用对象：**招标 / 采购业务人员**（非技术）
> 目标：读完本手册，你会用这个工具快速查标书里的关键信息，并看懂它给的每句话。

---

## 一、这个工具能帮你做什么

把一本几十页的招标文件"装进"对话窗口。你用**大白话提问**，它从已上传的标书里找出相关原文，给你：

- ✅ **一句话答案**（基于标书事实，不瞎编）；
- 📎 **出处引用**（哪个文件、第几页，方便你回原文核对）；
- 🚦 **置信度**（high / medium / low，提示你该不该直接采信）。

### ⚠️ 一句话定位
它是**帮你快速找答案的助手，不是替你做决定的专家**。正式投标前，关键信息**一定要回原文复核**。

---

## 二、怎么打开

- 技术人员会给你一个网址（默认本地 `http://localhost:8501`），或已部署好的内网地址；
- 浏览器打开后，看到一个对话框就能用了。

（部署与启动由技术人员负责，详见《部署运维手册》。）

---

## 三、你能问什么（举例）

| 想查的信息 | 可以这么问 |
|------------|------------|
| 预算金额 | "ZB2026-001 这个项目的预算是多少？" |
| 投标截止 | "智能评标系统采购项目的投标截止时间？" |
| 招标人 | "这个项目的招标人是谁？" |
| 资质要求 | "投标需要具备什么资质？注册资本多少？" |
| 是否联合体 | "接受联合体投标吗？" |
| 评标权重 | "评标办法各项权重怎么分？" |
| 付款方式 | "合同付款怎么付？" |
| 服务/工期 | "质保期多久？服务期多长？" |
| 汇总 | "列出本次所有项目的名称和编号。" |

---

## 四、怎么问，效果更好

1. **带上项目名或编号**：说"ZB2026-001"比说"第一个项目"更准。
2. **用完整句子**："预算是多少"优于"预算"。
3. **一次问一件事**：别把五个问题揉成一句，拆开问更准。
4. **问文档里有的事**：它只认**已经上传的标书**，问标书之外的内容它会说"文档中未提及"。

---

## 五、怎么看它给的结果

每次回答由三部分组成：

- **答案**：直接给的结论。涉及金额、日期、责任主体时，它会**尽量照原文引用**。
- **引用（📎）**：点开能看到来源文件名 + 页码。这是你**回原文核对**的入口——建议关键决策前都点一下。
- **置信度（🚦）**：
  - 🟢 **high**：答案明确、有原文支撑，可直接参考；
  - 🟡 **medium**：有一定依据但可能不全面，建议核对；
  - 🔴 **low**：信息不足或文档未提及，务必自行查找。

### 右侧"高级参数"（一般不用动）
技术人员已调好默认值。若你发现老召回不相关内容，可让技术把"相似度阈值"调高；若漏召，可调低。

---

## 六、已知局限（请务必知悉）

1. **只认已上传的标书**：没传的、或传了但没建索引的，它查不到。
2. **不联网、不编外知识**：它不会"补充"标书以外的行业常识。
3. **可能看错分页/长条款**：极长或跨页的条款偶尔会切分不准，以**引用原文**为准。
4. **金额、日期、主体以原文为最终准绳**：AI 答案仅供参考。

---

## 七、免责声明

> 本工具输出**仅供参考**，不构成任何投标或法律意见。所有关键条款（预算、资质、截止时间、评分、付款等）**须以招标文件正式纸质/官方电子文本为准**，并经人工复核后使用。
